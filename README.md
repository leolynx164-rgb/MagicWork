<h1 align="center">MagicWork</h1>

<p align="center">
  <strong>L'IA pour mieux travailler.</strong>
</p>

MagicWork est une application de bureau qui rassemble des outils d'intelligence artificielle pour simplifier le travail scolaire.

## ✦ Outils

* ⚡ Générateur d'exercices
* 📄 Simplificateur d'exercices
* 📝 Résumeur de cours
* 📋 Fiches de révision
* ✅ Générateur de QCM
* ✓ Correcteur de devoirs
* 🔢 Résolution de problèmes mathématiques
* 📚 Générateur de sujets d'examen
* 🃏 Flashcards interactives


## ✦ Build

```bash
git clone https://github.com/leolynx164-rgb/MagicWork.git
cd MagicWork
npm install
```

## ✦ Lancer

```bash
npm start
```

## ✦ API

MagicWork peut utiliser **Google Gemini** ou **OpenRouter**.

Les clés API sont configurables directement dans l'application.
